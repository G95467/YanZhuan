焰转 · 格式转换工坊  v1.0.2

一、这是什么
焰转是一个完全在本机运行的文件格式转换工具。支持视频、音频、图片、Markdown / Word /
HTML / TXT / RTF / ODT 文档，以及 Windows ESD 镜像转 ISO。转换过程不联网上传文件。

二、打开应用
双击“焰转.exe”。普通格式转换不需要管理员权限。
只有“ESD 转 ISO”会弹出 UAC 管理员授权，因为需要调用 Windows DISM 展开系统镜像。

三、常用转换
- MP4 保留音频为 MP3：添加 MP4，目标格式选 MP3。
- MD 转 Word：添加 .md，目标格式选 DOCX。
- ESD 转 ISO：添加 .esd，目标格式选 ISO。
- 图片：PNG / JPG / WebP / BMP / GIF / TIFF 互转；GIF 也可以转成 MP4。
- 视频 / 音频：MP4、MKV、MOV、AVI、WebM、TS、MP3、WAV、M4A、AAC、FLAC、OGG、OPUS 等。
- 文档：Markdown、Word、HTML、TXT、RTF、ODT 之间互转。
- Word 专属：Word 转 Excel（正文写入“正文”表，文档表格分别写入独立工作表），
  Word 转 PDF（Pandoc + Edge 打印，保留中文和表格样式）。仅支持 .docx。
- PDF 转 PPT：把 PDF 每一页渲染成高清图片，再生成对应页数的 PPTX。
- 视频转 GIF：视频文件的目标格式选择 GIF。
- 图片转文字：使用 Windows 自带 OCR 识别图片文字，输出 TXT。
- 表格数据：CSV 与 JSON 互转，保留中文、引号、逗号和单元格内换行。
- 字幕：SRT 与 VTT 互转，保留时间轴和字幕文本。

Word 转 Excel、Word 转 PDF、PDF 转 PPT 都不需要安装 Microsoft Office。
Word 转 PDF 使用系统自带的 Microsoft Edge；图片转文字需要 Windows 已安装
中文或英文 OCR 语言包（大多数中文 Windows 已自带）。

四、保存位置和文件命名
第一次使用时，转换结果默认保存到 Windows 的“下载”文件夹。
可以在“设置”里更改保存文件夹，也可以修改命名模板：
  {name}    原文件名（不含扩展名）
  {format}  目标格式
  {date}    日期，例如 20261115
  {time}    时间，例如 143000
  {index}   序号，例如 01
例如模板 {name}_{format}_{date} 会生成：旅行视频_mp3_20261115.mp3
文件名会自动清理非法字符，不会出现乱码；同名文件会自动追加序号。

五、大文件和流光下载器
当源文件或转换结果达到或超过 300MB 时，焰转会弹出应用内提示，询问是否使用
“流光下载器”进行高速下载。你可以选择“暂不使用”，焰转不会做任何额外操作，转换结果
已经保存在本地。
如果选择“使用流光下载器”：
1. 焰转会先检测本机是否已安装流光下载器。
2. 如果尚未安装，会打开焰转安装目录里的“流光下载器-安装程序-v1.0.2.exe”，
   由你手动完成安装；焰转不会静默安装。
3. 安装完成后回到焰转，点击“重新检测”。
4. 检测到已安装后，焰转会在本机启动一个临时 HTTP 下载服务，生成
   http://127.0.0.1:端口/... 的临时链接，并显示“复制”按钮。
5. 点击“复制”，链接会进入 Windows 剪贴板；打开流光下载器新建任务并粘贴即可。
链接只在本机回环地址上提供，带随机令牌，约 20 分钟有效；关闭焰转后立即失效。

六、转换速度与进度
媒体转换由 FFmpeg 执行，界面会显示“分析 → 转换 → 写入 → 完成”的步骤和实时百分比。
文档转换由 Pandoc 执行，ESD 转 ISO 由 Windows DISM + IMAPI2 执行。
速度主要取决于源文件大小、编码格式和电脑性能；尽量使用性能模式并关闭占用磁盘的程序。

七、ESD 转 ISO 的说明
- ESD 会先展开到系统临时目录，因此需要足够的磁盘空间（通常数 GB 到十几 GB）。
- 选择 ESD 中第 1 个映像索引。
- 生成的是数据 ISO，包含 Windows 安装文件，默认不包含启动引导；如果需要可启动安装盘，
  请使用微软官方 Media Creation Tool 或 ADK 的 oscdimg 制作。
- 需要管理员权限；如果取消了 UAC，本次转换会停止，不会留下不完整文件。

八、运行环境
- Windows 10 / 11 x64
- .NET 10 Desktop Runtime
- Microsoft Edge WebView2 Runtime
- 安装目录内的 tools 文件夹包含 FFmpeg、Pandoc 和 ESD 转换组件，请勿删除。

九、数据与卸载
设置保存在 %LOCALAPPDATA%\YanZhuan，日志在 logs\app.log。
安装版可直接在“设置 → 应用”中卸载，卸载程序会删除整个安装目录（包括 Source 和
安装目录中的流光下载器安装程序副本）。请不要把自己的个人文件放进焰转安装目录。
便携版删除整个文件夹即可。
